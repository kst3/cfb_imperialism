# NFL logo variants

- `giants.svg`: https://upload.wikimedia.org/wikipedia/commons/6/60/New_York_Giants_logo.svg (blue ny mark with red border).
- `jets-white.svg`: https://static.www.nfl.com/t_q-best/league/api/clubs/logos/NYJ (white Jets mark with green border).

Downloaded September 30, 2026. Artwork is unmodified. Team marks belong to their respective owners; this is an unofficial fan project. Include `assets/logos/` when uploading the site. These assets also work offline.
